# 自学坊

自学坊（[selftaught.fun](https://selftaught.fun/)）是一个由社区共同维护的开放自学地图。我们整理各学科的学习路径、大学公开课、开放教材和实践项目，帮助学习者系统、公开、实践地获得知识。

> 我们相信，科技终将抹平信息差，让任何人都能自由抵达知识。

目前网站重点完善金融、数学、计算机、自然科学、社会科学、工程、语言与文学等学科，并通过知识图谱展示它们之间的联系。

## 参与贡献

欢迎通过以下方式参与：

- 在 Issues 中推荐资源、报告失效链接或指出内容错误；
- Fork 仓库并提交 Pull Request；
- 参与 Issue 和 Pull Request 中的公开讨论；
- 帮助验证课程质量、前置要求和链接可用性。

提交前请先阅读 [贡献指南](CONTRIBUTING.md) 和 [内容收录标准](docs/CONTENT_STANDARDS.md)。所有进入官方网站的修改都需要维护者审核。仓库管理者可参考 [维护者指南](docs/MAINTAINER_GUIDE.md) 配置分支保护和审核流程。

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

提交修改前请运行：

```bash
npm run lint
npm run build
```
