# 内容收录与审核标准

本标准适用于自学坊中的公开课、教材、书籍、论文、工具、学习路径和知识图谱关系。

## 一、基本原则

所有内容应同时服务于三个目标：

1. **系统**：说明学习顺序、知识关系和前置要求；
2. **公开**：优先选择合法、稳定、无需付费即可学习核心内容的资源；
3. **实践**：帮助学习者通过习题、实验、写作、代码或项目形成能力。

## 二、资源优先级

优先收录：

1. 顶尖大学或权威机构发布的完整公开课程；
2. 作者、大学或开放教育机构合法发布的开放教材；
3. 有明确作者、出处和长期维护记录的专业资料；
4. 能提供练习、作业、项目或反馈机制的资源；
5. 在已有资源之外带来明显价值的中文优质资源。

一般不收录：

- 只有宣传页、缺少核心内容的课程；
- 盗版 PDF、网盘搬运、未经授权的镜像；
- 大量广告、强制付费或注册后仍无法访问核心内容的资源；
- 内容过时且没有历史学习价值的资料；
- 仅凭学校名气推荐、但不适合自学的课程；
- 重复度高且没有新增价值的资源。

## 三、单项资源必备信息

每项资源应尽可能包含：

| 字段 | 要求 |
| --- | --- |
| 名称 | 使用官方名称，不添加夸张修饰 |
| 链接 | 指向作者、学校或机构的原始页面 |
| 类型 | 公开课、开放教材、论文、工具或项目平台 |
| 难度 | 入门、进阶或高级 |
| 前置要求 | 写明真正需要掌握的知识，而非泛泛而谈 |
| 简介 | 说明覆盖内容、教学形式和适用人群 |
| 评价依据 | 引用公开评价、采用情况或说明维护者的判断依据 |
| 验证日期 | 记录最近一次确认链接与内容的日期 |

不得编造完成率、排名、用户评价或学校背书。主观判断必须清楚标明为编辑评价。

## 四、难度定义

- **入门**：默认学习者没有该学科基础，只要求通识数学、阅读或基础工具能力；
- **进阶**：要求完成本科基础课程，能够独立完成习题和小型项目；
- **高级**：通常接近本科高年级、研究生或研究训练，需要较强数学、编程、实验或文献阅读能力。

同一知识点优先形成入门、进阶、高级的梯度，而不是堆积同一难度的相似资源。

## 五、公开性判断

“公开”是指核心教学内容可以合法访问。允许：

- 可选注册；
- 付费证书，但课程内容可免费学习；
- 可购买纸质书，同时提供合法免费电子版。

必须在简介中注明：强制注册、地区限制、仅部分内容免费、历史课程不再维护等重要限制。

## 六、链接与时效性

- 提交前打开资源并确认标题、提供者和正文相符；
- 优先使用稳定的课程主页，不使用临时下载地址或搜索结果页；
- 页面迁移时更新为新的官方地址；
- 失效且没有官方替代的资源应删除或标注为历史资料；
- 自动检查出现 403、429 或超时时，需要人工浏览确认，不能直接判定失效；
- 网站定期运行链接检查，但自动检查不能替代内容审核。

## 七、课程路径

课程结构应参考该学科多所优秀大学的培养方案，而不是复制单一学校。每门课程需要：

- 服务于本学科的核心能力；
- 与前后课程有清晰关系；
- 避免把相邻学科课程机械复制进来；
- 给零基础学习者明确起点和阶段性成果；
- 最终连接到可验证的项目、研究或作品。

## 八、知识图谱

图谱中的连线必须代表可以解释的知识关系，例如前置关系、方法共享或明确的交叉学科。不能仅因两个领域“可能相关”就连线。新增交叉领域时，应在 Pull Request 中说明关系依据。

## 九、审核结论

维护者可以作出以下决定：

- **收录**：信息完整且符合标准；
- **修改后收录**：需要调整描述、位置、难度或链接；
- **候选观察**：资源有价值，但稳定性或开放性仍需观察；
- **不收录**：不符合版权、质量、范围或重复性要求。

学校名气不是唯一标准；准确、完整、适合自学和合法公开同样重要。
